      Infrastructure / Landing Zone
      VENDOR LEAD-TIME
      ExpressRoute circuit provisioning and Event Hubs Dedicated + zonal AKS capacity reservation in West Europe are external, vendor-lead-time items (weeks, not days) sitting on the critical path before either Data/Integration or Application Build can touch real infrastructure. A slip here has no parallel workaround and cascades directly into both downstream workstreams simultaneously.
      Data / Integration
      UNBENCHMARKED LEGACY
      The 280TB Teradata migration and 30+ source-system onboarding depend on legacy systems Acme itself is actively decommissioning through 2027 — extract throughput, SME availability, and network readiness at globally distributed sites (Mexico, Vietnam, Romania, Munich) have never been benchmarked (only real-time ingest at 250K events/sec has been tested, which says nothing about legacy batch-extract capacity). Since classification tagging gates both DR replication and Application Build's Power BI layer, any slip cascades through the entire downstream chain with no parallel workaround.
      Application Build
      NON-NEGOTIABLE AT RISK
      Application Build owns the RFP's one explicitly non-negotiable requirement (§2.3 Power BI, 600 users, including Austin DirectQuery), but its DirectQuery serving app sits at the end of a five-hop dependency chain entirely outside Application Build's control, with zero parallel workaround and full exposure to §4.3's "any duration" SLA-termination clause the moment it goes live late or degraded.
      Testing / Cutover
      ZERO FLOAT
      Testing/Cutover is the terminal node of a fully serial dependency chain: its riskiest sub-task, the DR failover drill, cannot even begin until the last links in Application Build's five-hop critical path are done, so this workstream inherits 100% of any upstream slip with zero float of its own. Because §4.3 makes any SLA miss "of any duration" an immediate-termination trigger against an architecture that only reaches 99.95% via a manual (not automated) DR-promotion runbook, the drilled recovery time — not calendar time — is the real gating variable for whether go-live can be responsibly approved at all.
      Common thread across all four flags: a single serial critical-path chain runs end-to-end through the delivery plan, with no parallel workaround at any link.
